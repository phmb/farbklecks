# Farbklecks

Ein kleines Touch-Spiel im Browser: Du bekommst eine Farbe gezeigt und mischst sie so genau wie möglich nach, entweder aus **RGB-Licht** oder aus **CMYK-Tinte**.

**Jetzt spielen:** https://phmb.github.io/farbklecks/

- Zieh mit dem Finger in den Reagenzgläsern, mit − und + stellst du fein nach.
- 5 Runden, bis zu 100 Punkte pro Runde, bewertet nach Farbabstand ΔE (CIEDE2000).
- Zwei Tipps pro Spiel (kosten je 10 Punkte) und ein Gedächtnis-Modus mit nur 3 Sekunden Blick auf die Zielfarbe.

Alles steckt in einer einzigen Datei, `index.html`, ohne Build-Schritt.
